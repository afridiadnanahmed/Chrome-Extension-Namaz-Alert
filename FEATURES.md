# Feature Ideas for Namaz Timings Extension

## Prayer & Worship Features

| Feature | Description | Priority |
|---------|-------------|----------|
| Qibla Direction | Compass showing Qibla direction based on user location | High |
| Athan/Adhan Sound | Play adhan audio at prayer times with sound selection | High |
| Prayer Tracker | Mark prayers as completed, track daily/weekly prayer history | Medium |
| Tahajjud Time | Show last third of night timing for Tahajjud prayer | Medium |
| Suhoor/Iftar Times | Ramadan mode with fasting times | High |

## Content Features

| Feature | Description | Priority |
|---------|-------------|----------|
| Daily Ayah | Display a verse from Quran that changes daily | High |
| Hadith of the Day | Random or daily hadith display | Medium |
| Dhikr Counter | Tasbih counter with presets (SubhanAllah, Alhamdulillah, etc.) | Medium |
| Islamic Calendar | Show important Islamic dates and events | Low |
| More Duas | Categorized duas (morning, evening, travel, eating, etc.) | Medium |

## Customization Options

| Feature | Description | Priority |
|---------|-------------|----------|
| Widget Size | Compact/Normal/Expanded popup modes | Low |
| Prayer Time Adjustments | Manual +/- minutes adjustment per prayer | High |
| Custom Notification Sounds | Upload or select different alert sounds | Medium |
| Language Selection | Arabic, Urdu, English translations | Medium |

## Utility Features

| Feature | Description | Priority |
|---------|-------------|----------|
| Nearby Mosques | Find mosques near current location using Google Maps API | Low |
| Multiple Locations | Save multiple cities and switch between them quickly | Medium |
| Export/Import Settings | Backup and restore settings | Low |
| Desktop Widget | Always-on-top mini window option | Low |

## Technical Improvements

| Feature | Description | Priority |
|---------|-------------|----------|
